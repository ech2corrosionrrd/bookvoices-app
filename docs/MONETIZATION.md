# Комерційна стратегія та бізнес-модель BookVoices

> **Продукт:** BookVoices — преміальний офлайн-плеєр аудіокниг для Android  
> **Модель бізнесу:** Freemium + Lifetime Pro (одноразова покупка)  
> **Цільова маржинальність:** **85%** (нульова собівартість інфраструктури, COGS ≈ $0)  
> **Головна конкурентна перевага:** Сучасний інтерфейс Material 3 / Cormorant, 100% приватність, 0 реклами, відсутність нав'язливих підписок.

---

> **Стан на 6 вересня 2026.** Продати Pro поки неможливо: SKU
> `bookvoices_pro_lifetime` не створити, доки не заведено обліковий запис
> продавця в Google Payments. Тобто весь розділ нижче — плани, а не чинні
> числа; жодної транзакції ще не було. Код монетизації при цьому готовий і
> лежить у релізі. Стан Console — [`play-store/README.md`](play-store/README.md).

## 1. 🎯 Продуктове позиціонування та ринкова ніша

BookVoices позиціонується як **найкращий сучасний інструмент для людей із власною колекцією аудіокниг** (DRM-free MP3, M4B, FLAC, OGG, OPUS, навчальні лекції, професійні курси).

### Чому користувачі готові платити?
1. **Втома від підписок (Subscription Fatigue)**: Більшість сучасних сервісів вимагають $10–15 щомісяця. BookVoices пропонує чесну модель: «Купив один раз — володієш назавжди».
2. **Застарілі конкуренти**: Лідер ринку (*Smart AudioBook Player*) має застарілий інтерфейс 2014 року. BookVoices надає вишуканий дизайн (Cormorant, анімації, теми, адаптивні макети).
3. **100% Приватність та офлайн**: Відсутність аналітики, трекерів, реєстрацій та передачі даних третім особам.

## 3. 📈 Юніт-економіка та фінансова модель

Завдяки архітектурі **Local-First**, у продукту **відсутні серверні витрати (COGS = $0)**.

| Метрика | Значення |
| :--- | :--- |
| **Ціна Pro Lifetime** | **$4.99** (верхня межа розібраного діапазону еластичності) |
| **Комісія Google Play** | 15% (за програмою Google Play Reduced Service Fee) |
| **Чистий виторг з 1 ліцензії** | **$4.24** ($4.99 − 15% комісії) |
| **Вартість серверів / трафіку на користувача** | **$0.00** |
| **Операційна маржа** | **🔥 ~85%** |

### Фінансовий прогноз при конверсії 3.5% (стандарт для утиліт):

```
10 000 установок / міс × 3.5% конверсія = 350 Pro-продажів
350 × $4.24 (net) = ~$1 484 / міс чистого прибутку

50 000 установок / міс × 3.5% конверсія = 1 750 Pro-продажів
1 750 × $4.24 (net) = ~$7 420 / міс чистого прибутку
```

## 4. 🛠️ Технічна реалізація монетизації (Google Play Billing 8.x)

1. **Бібліотека**: `com.android.billingclient:billing-ktx:8.0.0+` (з 31.08.2026 Play відхиляє оновлення на старших версіях).
2. **SKU**:
   - `bookvoices_pro_lifetime` (одноразова покупка / Non-consumable).
   - Інших SKU немає: у коді визначено рівно один — `SKU_PRO_LIFETIME`.
3. **Архітектура збереження стану ліцензії**:
   - `ProEntitlementManager` — єдиний клас, що працює з Play; окремого
     `BillingRepository` не існує.
   - Стан ліцензії кешується в `EncryptedSharedPreferences` (`SecretStore`) для
     миттєвої роботи в 100% офлайні.
   - `queryPurchasesAsync` виконується при кожному з'єднанні з Play і має право
     **знімати** Pro: повернення коштів чи відкликання покупки скидають і кеш,
     і маску в `UserPrefs`.
   - Кнопка «Restore Purchases» у paywall — ручна, для перенесення ліцензії на
     новий пристрій. Автоматично при старті вона не викликається.

## 5. 🚀 Стратегія виходу на ринок (Go-To-Market & ASO)

1. **App Store Optimization (ASO)**:
   - Ключові слова (7 локалей): *Audiobook Player, Offline Audiobooks, M4B Player, Smart Audio Book, Folder Player, No Ads, WebDAV sync*. Для pt-BR ключі мають бути свої (*audiolivro, tocador de audiolivros, offline*), а не переклад англійських.
   - Локалізовані скріншоти підкреслюють дизайн (OLED, графік активності, плеєр). Кадр із Pro-функцією обовʼязково має підпис «Pro» — вимога Play до платного вмісту.
2. **Органічний трафік у профільних спільнотах**:
   - Публікація на Reddit (`r/audiobooks`, `r/androidapps`, `r/privacy`, `r/de_EDV`).
   - Огляди на тематичних форумах та платформах (Product Hunt, F-Droid / IzzyOnDroid для безкоштовної версії).
3. **Репутаційний маркетинг**:
   - Підкреслення відсутності реклами та поваги до конфіденційності користувача.

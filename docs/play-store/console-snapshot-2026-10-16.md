## Android Vitals — 3 рекомендовані дії (для 11300)

Без змін від розбору 12.10.2026 (див. `README.md` цієї теки, «Рекомендації Console до випуску 11300»):

1. Безрамковий показ (edge-to-edge) може працювати не для всіх користувачів — стандартний текст для
   `targetSdk` 35+; `enableEdgeToEdge()` у коді є.
2. Застарілі API для безрамкового показу (`setStatusBarColor`, `setNavigationBarColor`, `SHORT_EDGES`) —
   код бібліотек `androidx.activity`/`androidx.core`, не наш; зникне з оновленням бібліотек.
3. Роздільна здатність бітових карт (використання пам'яті) — джерело однозначно не встановлено;
   власні `BitmapFactory` використовують `inSampleSize`.

Рекомендації стосуються 11300; чи зникнуть вони для 11400, видно буде після публікації.

# Скріншоти для Google Play (телефон)

## Актуальний набір — 1.17.0 (8 листопада 2026), усі 7 мов

Теки `v1.17-en`, `v1.17-uk`, `v1.17-pl`, `v1.17-de`, `v1.17-es`, `v1.17-fr`, `v1.17-pt-BR`, по 8 кадрів 1080×2160:
`01-shelf`, `02-player`, `03-shelf-grid`, `04-bookmarks`, `05-history`, `06-sleep-timer`, `07-settings`,
`08-shelf-paper`. Порядок у Console такий самий. Внесено в Console 8 листопада 2026 для всіх 7 мов.

Як знято: емулятор `BV_API35` (override 1080×2160), демо-режим статус-бару (9:41, повна батарея, Wi-Fi `fully`),
debug-збірка `app.bookvoices.debug`, тека `/sdcard/Audiobooks` (8 публічних творів, імпорт «Папка з
розділами»). Прогрес, тиждень (5 год 35 хв), сесії, закладки й мітки засіяно в базу через
`run-as … sqlite3`. Назви розділів і нотатки закладок — мовою кадру (як після «Пронумерувати»).
Пастки: на полиці не тягнути вниз біля верху (pull-to-refresh показує підказку про папку бібліотеки);
у Console завантажувати кадри по одному з паузою ~9 с, інакше частина губиться й порядок плутається;
у мовних сторінках сірі кадри — успадковані з en-US, власні їх перекривають.


## Актуальний набір — 1.14.0 (16 жовтня 2026)

Знято на емуляторі Android 15 (`BV_API35`), 1080×2160 (2:1 — максимум для Play), демо-режим системної
панелі (9:41, повна батарея), збірка debug із `master` після `e0c0c37`. Тека `Audiobooks` із 8 публічними творами
(Остін, Веллс, Стокер, Керролл, Дойл, Стівенсон, Шеллі, Верн); аудіо — тихий тон, обкладинки генерує сам
застосунок. Прогрес, історія за тиждень, закладки з нотатками й мітки засіяні в БД (`sqlite3` через `run-as`).
Файли: `v1.14-en/` (8 кадрів) і `v1.14-uk/` (7 кадрів, без теми «Папір»).

Порядок у Console (і в чернетці, збереженій 16.10.2026): полиця → плеєр → сітка → закладки → історія → таймер сну
→ налаштування → (лише en) тема «Папір».

| Файл | Що на кадрі |
|---|---|
| `01-shelf` | Полиця: статистика тижня (5 год 35 хв), «Continue listening», сітка |
| `03-player` | Плеєр: підписані дії внизу (Queue, Characters, Chapters, Bookmark), позначка закладки |
| `02-shelf-grid` | Сітка книг із прогресом |
| `05-bookmarks` | Закладки з нотатками та пошуком |
| `06-history` | Історія: тижневий графік, сесії по днях |
| `04-sleep-timer` | Таймер сну |
| `07-settings` | Теми, 7 мов |
| `08-shelf-paper` | Світла тема «Папір» (лише en) |

Знімки планшетів (`tablet7-*`, `tablet10-*`) — старіші, від 12.10 (до оновлення екрана плеєра); у Console лишились
як були.

Як зняти заново: емулятор `BV_API35`, `wm size 1080x2160`, demo-режим `com.android.systemui.demo`, теку книг
покласти в `/sdcard/Audiobooks`, імпорт — «Add book → Folder with chapters»; `adb exec-out screencap -p`.
Пастка: з чипом «Jump back to …» на екрані плеєра кнопка паузи на 2:1 обрізається знизу — кадр знімати після
закриття чипа.

## Попередній набір — 12 жовтня 2026 (застарів)

Знято 12 жовтня 2026 на емуляторі Android 15 (`BV_API35`, Pixel 5), розмір екрана 1080×2160
(співвідношення 2:1 — максимум, який приймає Play для телефона), демо-режим системної
панелі (9:41, повна батарея). Збірка debug із `master` після `f232d10`. Тека з тестовими
книгами — публічні твори (Остін, Веллс, Стокер, Керролл, Дойл, Стівенсон), обкладинки
намальовано скриптом, чужої графіки немає. Аудіо — тиша з тихим тоном, на кадрах його не видно.

| Файл | Що на кадрі | Підпис, який можна накласти |
|---|---|---|
| `phone-en/01-shelf` | Полиця: статистика тижня, «Continue listening», сітка | Your own audiobooks, one shelf |
| `phone-en/02-shelf-grid` | Сітка шести книг із прогресом | Covers, progress, tags |
| `phone-en/03-player` | Плеєр: глава, швидкість, таймер сну | Pick up where you left off |
| `phone-en/04-book` | Книга: мітка, глави, нотатки, персонажі | Chapters, notes, tags |
| `phone-en/05-bookmarks` | Закладки з нотатками та пошуком | Bookmarks with notes |
| `phone-en/06-settings` | Теми, 7 мов, налаштування | 7 languages, 3 themes |
| `phone-en/07-shelf-paper` | Світла тема «Папір» | Paper theme |
| `phone-uk/01…04, 06` | Те саме українською (без закладок) | Власні аудіокниги на одній полиці та ін. |

Що відомо про кадри:
- На кадрах видно плаваючу кнопку «додати книгу» справа; вона частково перекриває
  обкладинку другої книги, як і в застосунку.
- Закладок українською немає: нотатки в них англійською, а для Play вони не потрібні.
- Старі кадри у цій теці (`01-shelf-1080x2160.png` тощо, вересень) застарілі: інший
  вигляд верхньої панелі. Нові лежать у `phone-en/` і `phone-uk/`.
- Підписи накладаються окремо (у Console їх немає); без накладання кадри теж придатні.

Як зняти заново: `scripts/` не містить автоматики; кроки — у розділі «Скріншоти» репозиторної
історії коміту, що додав цю теку (емулятор BV_API35, `wm size 1080x2160`, demo-режим
`com.android.systemui.demo`, імпорт теки книг через вибір теки в застосунку).

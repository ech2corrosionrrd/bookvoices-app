# Скріншоти для Google Play (телефон)

Знято 12 жовтня 2026 на емуляторі Android 15 (`BV_API35`, Pixel 5), розмір екрана 1080×2160
(співвідношення 2:1 — максимум, який приймає Play для телефона), демо-режим системної
панелі (9:41, повна батарея). Збірка debug із `master` після `f232d10`. Тека з тестовими
книгами — публічні твори (Остін, Веллс, Стокер, Керролл, Дойл, Стівенсон), обкладинки
намальовано скриптом, чужої графіки немає. Аудіо — тиша з тихим тоном, на кадрах його не видно.

| Файл | Що на кадрі | Підпис, який можна накласти |
|---|---|---|
| `phone-en/01-shelf` | Полиця: статистика тижня, «Continue listening», сітка | Your own audiobooks, one shelf |
| `phone-en/02-shelf-grid` | Сітка шести книг із прогресом | Covers, progress, tags |
| `phone-en/03-player` | Плеєр: глава, швидкість, таймер сну | Pick up where you left off |
| `phone-en/04-book` | Книга: мітка, глави, нотатки, персонажі | Chapters, notes, tags |
| `phone-en/05-bookmarks` | Закладки з нотатками та пошуком | Bookmarks with notes |
| `phone-en/06-settings` | Теми, 7 мов, налаштування | 7 languages, 3 themes |
| `phone-en/07-shelf-paper` | Світла тема «Папір» | Paper theme |
| `phone-uk/01…04, 06` | Те саме українською (без закладок) | Власні аудіокниги на одній полиці та ін. |

Що відомо про кадри:
- На кадрах видно плаваючу кнопку «додати книгу» справа; вона частково перекриває
  обкладинку другої книги, як і в застосунку.
- Закладок українською немає: нотатки в них англійською, а для Play вони не потрібні.
- Старі кадри у цій теці (`01-shelf-1080x2160.png` тощо, вересень) застарілі: інший
  вигляд верхньої панелі. Нові лежать у `phone-en/` і `phone-uk/`.
- Підписи накладаються окремо (у Console їх немає); без накладання кадри теж придатні.

Як зняти заново: `scripts/` не містить автоматики; кроки — у розділі «Скріншоти» репозиторної
історії коміту, що додав цю теку (емулятор BV_API35, `wm size 1080x2160`, demo-режим
`com.android.systemui.demo`, імпорт теки книг через вибір теки в застосунку).

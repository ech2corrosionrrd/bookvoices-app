## Повний опис

### Українська

BookVoices — плеєр для **ваших** аудіокниг на телефоні.

- Імпорт mp3, m4b, ogg, flac з теки або окремих файлів
- Полиця з обкладинками, пошуком, тегами, серіями та фільтром «файли зникли»
- Плеєр: швидкість, закладки, таймер сну, черга «далі»
- Історія з графіком за тиждень, місяць або рік; екран циклу (серії)
- Експорт каталогу та закладок у Markdown
- Фонове відтворення, віджет, Android Auto
- Резервна копія прогресу (JSON або WebDAV)
- 7 мов інтерфейсу (UK, EN, PL, DE, ES, FR, pt-BR), тема OLED, без реклами

Файли лишаються на диску. Без акаунта. Без підписки.

**BookVoices Pro** — одноразова покупка, без підписки: пропуск тиші та пауз,
апаратний Volume Boost (+6 dB), голосовий еквалайзер із корекцією тону,
автозакладка при розриві Bluetooth, список персонажів книги. Решта функцій —
безкоштовно й без реклами.

### English

BookVoices plays **your** audiobooks stored on your phone.

- Import mp3, m4b, ogg, flac from folders or files
- Library with covers, search, tags, series, and «missing files» filter
- Player: speed, bookmarks, sleep timer, Up Next queue
- Listening history with week/month/year charts; dedicated series screen
- Export library catalog and bookmarks as Markdown
- Background playback, home-screen widget, Android Auto
- Progress backup (JSON or optional WebDAV)
- 7 UI languages (UK, EN, PL, DE, ES, FR, pt-BR), OLED theme, no ads

Files stay on disk. No account. No subscription.

**BookVoices Pro** — a one-time purchase, no subscription: silence and pause
skipping, hardware Volume Boost (+6 dB), voice equalizer with pitch correction,
auto-bookmark on Bluetooth disconnect, and per-book character lists. Everything
else is free, with no ads.

## Data safety (відповіді)

| Питання | Відповідь |
|---|---|
| Збираєте дані? | Ні (або «No data collected») |
| In-app purchases | Так — одна опційна покупка, BookVoices Pro Lifetime; базове слухання безкоштовне |
| Дані передаються третім сторонам? | Ні |
| Дані шифруються в транзиті? | Лише якщо користувач увімкнув HTTPS WebDAV (опційно) |
| Можна видалити дані? | Так — видалення застосунку або книг у застосунку |

## Скріншоти (мінімум 2, рекомендовано 6–8)

1. Полиця (сітка книг)
